🧠 PROYECTO APP DE ESCRITORIO – LOGIN Y AUTENTICACIÓN CON FASTAPI (JWT)
=====================================================================

👋 BIENVENIDA
--------------
Vamos a implementar un **sistema de login en una app de escritorio Python (PySide6)**,
que se autentica contra un **backend FastAPI con JWT**, para que:

- Cada usuario se identifique con usuario/contraseña
- Se obtenga un JWT
- El JWT se use en TODAS las peticiones posteriores
- El backend pueda saber exactamente quién hizo cada acción
- La app funcione igual en cualquier computadora con el mismo ejecutable

🎯 OBJETIVO FINAL:
- App con pantalla de login
- Autenticación contra API FastAPI
- Almacenar JWT de forma segura
- Todas las operaciones se hacen “a nombre” del usuario autenticado
